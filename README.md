# Projeto Web - Lucas

##  Conceitos aplicados
- **Usabilidade:** menus simples e consistentes.
- **UX:** layout limpo, botões com feedback visual.
- **Acessibilidade:** uso de `alt` em imagens, contraste adequado.
- **Responsividade:** media queries para celular e desktop.

##  Escolhas de design
Optei por um layout minimalista para facilitar a navegação. As cores foram escolhidas para garantir contraste e acessibilidade. O menu responsivo permite uso em diferentes dispositivos.

##  Tarefas realizadas
- Criação da página inicial (index.html).
- Criação da página "Sobre" (sobre.html).
- Desenvolvimento do CSS responsivo.
- Configuração do GitHub Pages e documentação no README.
